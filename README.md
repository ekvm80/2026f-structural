## 계산의 정확성

세 개의 해석 엔진이 들어 있고, 폐형해(closed-form)와 대조해 **49개 항목을 검증**했습니다.

- **트러스 해석기** — 절점법 선형계 솔버 (워런 · 프랫 · 하우)
- **보 해석기** — 단순보 · 캔틸레버 · 내민보 × 집중 / 등분포 / 모멘트 하중
- **단면 성질 엔진** — 폭 함수 수치적분으로 A · 도심 · I · S · Q(y)

검증 예: `wL²/8`, `PL³/3EI`, `bh³/12`, `πd⁴/64`, 트러스 사재 `30√2 = 42.4264`,
주응력 `116.03 / −6.03`, 처짐 수치적분 `35.5555` vs 이론 `35.5556` mm

## 기술

- 의존성 없는 순수 HTML · CSS · Canvas 2D (프레임워크·빌드 도구 없음)
- **IBM Carbon Design System** — Gray 100 / White 테마, Blue 60 인터랙티브, IBM Plex
- 밝게 / 어둡게 자동 전환 (시스템 설정 인식 + 수동 토글)
- 모바일 대응 — 좁은 화면에서 글자 크기와 그림 비율이 함께 조정됨
- 접근성 — 본문·태그 전 색상 WCAG AA 통과, 2px 포커스 링
